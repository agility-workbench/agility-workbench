# Grid API

`IGridAPI` is available from React's `ref`/`onGridReady`, Angular's `gridReady`
output or template reference, and `initDomRenderer()` in a core integration.

## Data and columns

| Method | Purpose |
| --- | --- |
| `setRowData(rows)` | Replace client-side rows |
| `applyTransaction(tx)` | Add, update, or remove client-side rows; returns `{ added, updated, removed }` counts of what was actually applied (unknown row IDs are skipped and not counted) |
| `setColumnDefs(defs)` | Replace column definitions |
| `getColumnState()` | Capture width, order, pinning, and visibility |
| `applyColumnState(state, options?)` | Merge or exactly restore state |
| `getColumnModel()` | Read runtime columns and sections |
| `refreshServerSideData(options?)` | Soft-refresh or purge a server cache/subtree |

## View and grouping

| Method | Purpose |
| --- | --- |
| `setQuickFilter(text, options?)` | Apply client-side global search |
| `getFilterModel()` | Read the per-column filters as serializable `{ colId, filters, join }` items |
| `setFilterModel(filters)` | Replace all column filters (empty array clears; resets to page 1 and clears selection) |
| `addFilterModel(filter)` | Add or replace one column's filter, keeping the others |
| `removeFilterModel(colId)` | Remove one column's filter (no-op when it has none) |
| `getSetFilterValues(colId)` | Set-filter columns: the value universe (null = blanks) |
| `getSetFilterState(colId)` | Intent-level `{ mode, checked, unchecked }`, or null when unfiltered |
| `checkSetFilterValue(colId, value)` / `uncheckSetFilterValue(colId, value)` | Toggle one value by intent |
| `setSetFilterValues(colId, values, { mode }?)` | Replace the set filter; `mode` pins include/exclude semantics |
| `setAllGroupsExpanded(expanded)` | Expand/collapse all groups in one pass |
| `captureViewState()` | Capture columns, groups, sort, filters, search, expansion, page |
| `applyViewState(state, options?)` | Restore a captured view |
| `setKeyboardNavigationMode(mode)` | Switch tree grid/hierarchy navigation |

Filter methods address columns by the public `ColDef.colId`. Grouping columns
and explicit sort models use typed `dispatch()` actions.

## Selection and navigation

`setFocusedCell`, `selectRange`, `extendRangeTo`, `selectRow`, `selectColumn`,
`selectAll`, `selectAllRows`, `clearSelection`, and `navigate` mirror rendered
keyboard and pointer behavior. `getSelection`, `getSelectedRows`, and
`getSelectedNodes` return current state.

## Editing and clipboard

| Method | Purpose |
| --- | --- |
| `startEditingCell(cell)` | Begin editing `{ rowId, colId }` |
| `stopEditing(value)` / `cancelEditing()` | Finish or cancel the active edit |
| `setCellValue(cell, value)` | Parse and write without opening an editor |
| `copySelection()` / `cutSelection()` / `paste()` | Clipboard workflows |
| `undo()` / `redo()` | Traverse edit history |
| `canUndo()` / `canRedo()` / `clearHistory()` | Inspect or reset history |

## Floating UI and pinned rows

`showTooltip`, `hideTooltip`, `openActionFrame`, and `closeActionFrame` address
cells by stable row and column IDs. `setPinnedTopRowData`,
`setPinnedBottomRowData`, and `setRowPinned` update frozen row bands.

## Export

`exportDataAsCsv` and `exportDataAsExcel` download files. `getDataAsCsv` and
`getDataAsExcel` return content for custom upload, encryption, or storage.

## Events and cleanup

Subscribe with `api.on(eventName, handler)` and call the returned unsubscribe
function. `destroy()` releases the grid when a custom host owns its lifecycle.

:::warning `colId` in event payloads is the internal instance ID

The `colId` fields carried by event payloads (`cellsChanged`, `cellValueChanged`,
`editingChanged`, `columnsChanged`, `onCellValueChanged`, …) hold the column's
internal instance ID — a per-instance UUID — **not** the `colId` you set on the
column definition. Translate before comparing against your own IDs:

```ts
const publicColId = api.getColumnModel().getById(ev.colId)?.colId;
```

The reverse lookup is `api.getColumnModel().getByColId(myColId)?.instanceID`.

:::
